# 📖 Overview

**Tunnel to Excel Automation** is an automation project developed to simplify and accelerate tunnel inspection and reporting processes.

Instead of manually transferring collected information into spreadsheets, the system automatically processes available data and generates structured Excel outputs. This significantly reduces repetitive work, minimizes human error, and improves reporting consistency.

The project demonstrates how automation can increase efficiency in engineering and infrastructure workflows while maintaining data accuracy.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/fatihguloglu34/Tunnel-to-Excel-Automation.git
```

Go to the project folder

```bash
cd Tunnel-to-Excel-Automation
```

Install the required dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python main.py
```
